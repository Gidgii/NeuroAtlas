# P1.9 — Progressive Competency Mapping

Adds a separate competency layer so completion and overall mastery are no longer treated as equivalent to clinical reasoning competence.

## Competencies

1. Recognise — identify the core structure, process, or principle.
2. Explain — accurately explain the concept in the learner's own words.
3. Localise — place structures/pathways in anatomical or network context when the concept has spatial/pathway content.
4. Compare — distinguish intact and disrupted function when comparison/lesion content exists.
5. Apply — use the concept in assessment or integrated clinical reasoning when those labs exist.

## Progressive retrieval

The review engine now selects the next competency using evidence rather than cycling blindly. Recognition is sampled first; explanation follows once recognition is sufficiently established; higher-order competencies then become the retrieval target where the concept supports them. Weak or unsampled higher-order skills are prioritised.

## Progress UI

The Progress page now displays an evidence-based competency profile and shows the next reasoning target beside each retrieval priority.

## Safety / scope

Application prompts explicitly require converging evidence, competing explanations, and limits on inference. Clinical competence is not inferred from simple exposure or one correct item.

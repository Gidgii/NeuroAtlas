Release information

Accessibility

Target: WCAG 2.2 Level AA practices. Status: not independently certified.

Current safeguards

  • Keyboard-accessible primary navigation, search and learning controls.
  • Programmatic names for visible controls and alternative text for concept hero illustrations.
  • Focus movement when routes change and a skip-to-content link.
  • Reduced-motion behaviour for interactive sequences.
  • Responsive layouts with automated mobile-overflow checks.
  • Minimum interactive target sizing strengthened in P5.
  • Forced-colour/high-contrast and print fallbacks where supported.

Known boundary

Automated tests cannot establish full WCAG conformance. Human keyboard, screen-reader, magnification, colour/contrast and cognitive-usability testing remains part of release governance before a formal conformance claim should be made.

Evidence and clinical accessibility

Core explanations remain concise, with optional deeper layers and an Evidence Library so users can inspect supporting sources without forcing dense material into the primary learning surface.

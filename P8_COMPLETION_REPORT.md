# Neuro Atlas P8 — Release Candidate Hardening

Candidate: **1.0.0-rc1**

P8 freezes major features and adds release-candidate governance, release metadata, offline cache coverage for P6/P7 and P8 assets, local beta feedback export, viewport browser QA, and an explicit licensing/third-party review inventory.

## Governance boundary

P8 does **not** claim independent clinical peer review, accessibility certification, legal/copyright clearance, or production security certification. Those remain explicit pre-v1.0 review items.

## Tag rule

Do not create the `v1.0-rc1` Git tag until the P8 commit has passed GitHub CI.

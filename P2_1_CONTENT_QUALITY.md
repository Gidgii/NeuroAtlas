# P2.1 — Content Quality Foundations

This pass begins P2 by closing the eight remaining registered-concept detail gaps and exposing the richer clinical content as an optional secondary layer.

## Changes

- Added production detail records for the eight foundational concepts that previously had curriculum cards but no detail JSON.
- Every registered curriculum concept now has learning objectives and references.
- Added a reusable **Deep dive** dialog. Main concept tabs remain concise; advanced detail, worked clinical examples, clinical relevance, pearls, and limitations sit behind one secondary button.
- Added a P2 content audit and regression tests for detail coverage, references, learning objectives, and deep-dive readiness.
- Updated offline precaching for the new module and eight detail files.

## Design rule

The primary page remains brief. Secondary clinical depth is available on demand rather than inserted into the default reading flow.

# P1.7 — Integrated Case-Based Neuropsychology Reasoning

P1.7 adds a sequential clinical-reasoning layer that requires learners to integrate presentation, localisation, assessment strategy, supporting evidence, contradictory evidence and competing explanations.

## Initial coverage

- Brainstem Atlas — 2 integrated cases
- Lesion and Symptom Mapping — 2 integrated cases
- Healthy Versus Pathology Comparison — 2 integrated cases

## Guardrails

The cases use working hypotheses rather than deterministic diagnosis labels. Each case includes evidence that would weaken or redirect the hypothesis, competing explanations, a next step, and an explicit caveat.
